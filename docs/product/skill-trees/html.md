# HTML — Зодчий (Строитель)

- **Источник полноты:** HTML Living Standard (WHATWG). Индекс уже есть: `docs/examples/html-course/spec-index.json` — все элементы и все атрибуты стандарта, тест курса проверяет покрытие.
- **Стоит на:** Браузер (ветка «Адрес страницы»).
- **Эволюции и союзники:** открывает CSS (после «Основ HTML») и JavaScript; союзник — Доступность (будущий персонаж).
- **Способности:**
  - Каркас — `html-document`, `html-elements`;
  - Смысл текста — ветка «Текст»;
  - Медиа — ветка «Картинки, видео и встраивание»;
  - Формы — ветка «Формы»;
  - Структура — ветка «Структура страницы»;
  - Метаданные — ветка «Head, поиск и безопасность»;
  - Доступность — ветка «Доступность».
- **Покрытие:** 68 навыков в 12 ветках покрывают весь стандарт; это сверено тестом индекса. Ниже — какие ветки чему соответствуют и чего не хватает игре.
