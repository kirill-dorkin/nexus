# CI/CD — Конвейер

- **Источник полноты:** документация GitHub Actions — синтаксис workflow полностью, события, выражения, контексты, переменные, секреты, окружения, матрицы, кэш, артефакты, переиспользуемые workflow и составные действия, OIDC, безопасность. Плюс общие практики CI/CD и обзор GitLab CI.
- **Стоит на:** Git (ранг Практик), Docker; Терминал.
- **Союзники:** Kubernetes, Vitest, Playwright. Процесс Nexus — живой пример: CI, деплой с миграциями (ADR-0079), smoke.
- **Способности:**
  - Конвейеры;
  - Тесты в CI;
  - Сборка и артефакты;
  - Секреты;
  - Деплой;
  - Безопасность цепочки.
- **Объём:** 23 навыка.

## Ветки

### Основа (Основа)
- `ci-what` — CI и CD, зачем, конвейер, шаги и задания
- `ci-workflow-syntax` — `on`, `jobs`, `steps`, `runs-on`, `uses`, `run`, `with`, `env`
- `ci-events` — `push`, `pull_request`, `workflow_dispatch`, `schedule`, фильтры путей и веток

### Конвейеры (Практика)
- `ci-expressions-contexts` — выражения, контексты `github`, `env`, `secrets`, `matrix`, `needs`, условия `if`
- `ci-matrix` — матрицы, `fail-fast`, `include`/`exclude`
- `ci-dependencies-outputs` — `needs`, выходы шагов и заданий, `GITHUB_OUTPUT`
- `ci-concurrency` — `concurrency`, отмена устаревших прогонов (как в Nexus)

### Скорость (Практика)
- `ci-cache` — кэш зависимостей и сборки
- `ci-artifacts` — артефакты, отчёты тестов

### Переиспользование (Продвинутое)
- `ci-actions-marketplace` — готовые действия, закрепление по SHA
- `ci-reusable` — переиспользуемые workflow и составные действия
- `ci-custom-actions` — свои действия на JS и Docker

### Секреты и окружения (Практика)
- `ci-secrets` — секреты, переменные, маскирование, окружения и правила защиты
- `ci-oidc` — OIDC: доступ в облако без долгоживущих ключей

### Деплой (Практика)
- `ci-deploy-strategies` — деплой: хуки, blue-green, canary, rollback, миграции до кода (ADR-0079)
- `ci-container-pipeline` — сборка и публикация образов, теги, мультиплатформенность
- `ci-release` — релизы, changelog, семантические версии

### Безопасность цепочки (Продвинутое)
- `ci-security` — минимальные `permissions`, `pull_request_target` и его опасность, инъекции в выражениях, сторонние действия
- `ci-supply-chain` — Dependabot, SBOM, подпись и provenance, проверка зависимостей

### Эксплуатация (Практика)
- `ci-runners` — GitHub-hosted и self-hosted раннеры, лимиты и минуты
- `ci-debugging` — отладка: логи, повтор с debug, локальный запуск (act, обзор)

### Справочник (Полное покрытие)
- `ci-syntax-reference` — синтаксис workflow полностью по индексу
- `ci-gitlab-overview` — GitLab CI (обзор и соответствие понятий)

**Бои:** конвейер «проверки → сборка → деплой» для учебного приложения; ускорить медленный конвейер вдвое; найти и закрыть уязвимость в workflow. Проверка — грейдер запускает workflow локальным исполнителем и проверяет результат.
