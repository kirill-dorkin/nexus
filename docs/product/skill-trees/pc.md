- **Источник полноты:** собственный индекс `docs/examples/pc-course/coverage-index.json` (#200) — устройство компьютера для будущего разработчика. Это не курс администрирования: глубже уходят персонажи Операционная система, Терминал и Сеть.

- **Способности:**

## Бои

Курс ПК без кода, поэтому бои — **практикумы с проверкой ответа**: ученик выполняет действие и вводит результат (хеш файла, размер, путь, вывод команды). Сервер проверяет ответ по эталону.

| Ветка | Бой |
|---|---|
| Двоичный мир | Расшифровать байты файла |
| Папки и пути | Найти файл по описанию и ввести полный путь |
| Командная строка | Собрать структуру проекта командами и ввести контрольную сумму архива |
| Диагностика | Найти причину по журналу событий |
