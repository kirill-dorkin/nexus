# ADR-0003: Stable identity + immutable published versions

- Status: Accepted

## Decision

Program/Course/Module/Lesson/Activity/Assessment/Question/Validator/Project use stable identity plus versioned immutable published revisions. Historical Attempt points to exact ActivityVersion; exact validators/results remain reproducible.

## Consequences

Corrections that change semantic content create a new draft/version. Published historical graphs remain addressable even after retirement.
