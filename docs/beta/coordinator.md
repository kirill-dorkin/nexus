# Координатор первой волны: запуск и еженедельная работа

Правила — в `docs/roadmap/beta-launch.md` (#207). План — в `wave-1-plan.md`, тексты — в `texts.md`.

**Журнал участников, их контакты и работы не хранить в git.** Только в закрытой таблице координатора.

## 1. До приглашений — один раз (≈2 часа)

### 1.1 Проверка продакшена своим тестовым аккаунтом

Пройти на компьютере, затем на телефоне. Использовать отдельный тестовый аккаунт, не личный.

| # | Шаг | Ожидаемо | ✓ ПК | ✓ Телефон |
|---|---|---|---|---|
| 1 | Открыть `/courses/html/how-the-web-works` без входа | Урок открывается, видны квизы | | |
| 2 | Нажать «Начать бесплатно», зарегистрироваться | Возврат на тот же урок | | |
| 3 | Ответить на квиз неверно, потом верно | Ответ проверяется и сохраняется, пересдача работает | | |
| 4 | Пройти все обязательные задания урока | Урок отмечен пройденным | | |
| 5 | Выйти и войти снова | Прогресс на месте, в «Моём обучении» курс с процентом | | |
| 6 | Урок 19 `/courses/html/project-recipe`: скачать заготовку, загрузить файлы с ошибкой, потом исправленные | Видны пункты проверки, затем «Задание выполнено» | | — |

Если какой-то шаг не работает — **не приглашать людей**, а сообщить разработке (Claude) с указанием шага.

### 1.2 Подготовка

- [ ] Канал связи с участниками: [Telegram-группа или личные сообщения]. Один для всех.
- [ ] Закрытая таблица-журнал (раздел 3).
- [ ] Тексты из `texts.md` проверены. Пункт про данные согласован, или есть ссылка на политику (#174).
- [ ] Выбраны 5 первых участников (раздел 2).

## 2. Набор: 5 → 20

1. **Первые 5** — приглашение и условия. Старт, когда человек ответил «Согласен(на)» и прошёл первый урок.
2. **3–5 дней наблюдения.** Если ни у кого нет препятствий — входа, сохранения прогресса, заданий — приглашаем остальных до 20.
3. **Препятствие найдено** — сначала исправление, потом набор.
4. **Траектория:** по ответу «писал ли HTML». «Нет» или «немного» → HTML, «уверенно» → CSS.

## 3. Журнал (закрытая таблица)

Одна строка — участник, вкладки — недели.

**Участники:** № · имя или ник · контакт · траектория (HTML/CSS) · старт (дата и время, Бишкек) · условия приняты (да/дата) · email аккаунта · статус (активен / пауза / приостановлен / завершил).

**Неделя N:** № · даты недели · учебные дни (0–3) · новые уроки (0–5, какие) · практика (ссылка на файл или «автопроверка урока N», принято/нет) · отзыв (да/нет, ссылка) · препятствия · решение координатора · предупреждение (да/нет).

### Как проверять норму вручную

Автоматических счётчиков пока нет — это пакет B1.2.
- **Новые уроки и дни.** Спросить в отзыве, что пройдено, и сверить с прогрессом курса у ученика: он присылает скриншот «Моего обучения» или страницы курса. Дни отмечать по его ответу и истории сообщений.
- **Практика с автопроверкой.** Ученик присылает скриншот «Задание выполнено».
- **Ручная практика.** Ученик присылает файл, координатор проверяет по критериям из плана и записывает «принято» с датой получения.
- **Сомнения** трактуются в пользу ученика. Сбой сайта — неделя `excused`.

## 4. Каждую неделю (≈30–60 минут на 20 человек)

- **За 48 часов до конца недели:** напоминание тем, кому не хватает нормы (`texts.md`, §6).
- **После конца недели:**
  1. Свести журнал.
  2. Короткий ответ каждому: что хорошо и что дальше.
  3. Карточка следующей недели.
- **Сводка для разработки (Claude):**
  - топ-5 проблем: что, где, сколько человек, цитаты;
  - топ-3 предложения;
  - что мешало учиться;
  - средняя оценка недели.

  По этой сводке выбираются исправления на следующую неделю.

## 5. Сообщения о проблемах

| Тип | Что делать |
|---|---|
| Не могу войти, пропал прогресс, задание не принимается | **Срочно:** сразу в разработку, участнику — пауза нормы до исправления |
| Ошибка в уроке: опечатка, неверный ответ в квизе | В сводку недели, исправляется в курсе и публикуется |
| Непонятно объяснено | В сводку: это главный материал для улучшения уроков |
| Идея или пожелание | В сводку, раздел «предложения» |

Ответ участнику — в течение суток: «принято, спасибо» или «исправлено».

## 6. Как поймём, что бета работает

Ориентиры — по `beta-launch.md`, раздел 9:

| Показатель | Ориентир |
|---|---|
| Сделали первую попытку за 24 часа после старта | ≥ 70% |
| Вернулись на второй неделе | ≥ 50% |
| Закрыли норму недели | ≥ 60% |
| Препятствия на обязательном пути | 0 открытых |

После двух полных недель — разбор с разработкой: что чиним, расширяем ли до 30–50 человек.
