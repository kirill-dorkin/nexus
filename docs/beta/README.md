# Закрытая бета: комплект первой волны (20 человек)

Решение владельца, 2026-11-05: запустить 20 учеников, которые учатся и тестируют. Развитие продукта идёт от их отзывов. Правила беты — `docs/roadmap/beta-launch.md` (#207).

| Файл | Что внутри |
|---|---|
| `coordinator.md` | Проверка продакшена перед приглашениями, набор 5 → 20, журнал, еженедельная работа, разбор проблем, ориентиры |
| `wave-1-plan.md` | 4 недели по 5 уроков и 1 практике: траектория HTML для новичков и CSS для знающих HTML |
| `texts.md` | Приглашение, условия, первый день, карточка недели, вопросы отзыва, напоминания, конец беты |

## Порядок запуска

1. **Владелец:** пройти таблицу проверки продакшена (`coordinator.md`, 1.1) тестовым аккаунтом на компьютере и телефоне.
2. **Владелец:** выбрать канал связи и согласовать пункт о данных в условиях (`texts.md`, §2, п. 8; шаблон #174).
3. **Владелец:** пригласить первых 5 (`texts.md`, §1–3), завести журнал.
4. **Через 3–5 дней без препятствий:** добрать до 20.
5. **Каждую неделю:** сводка отзывов → разработка исправляет главное → карточки следующей недели.

## Что делает разработка параллельно (B1, `beta-launch.md`, раздел 7)

Порядок выбран так, чтобы как можно раньше получать отзывы прямо в продукте:
1. **B1.3** — кнопка «Сообщить о проблеме» и недельный отзыв на сайте, сразу с контекстом страницы и версии. Входящие видны в Studio.
2. **B1.1 + B1.2** — участие в бете и страница «Моя неделя» со счётчиками, чтобы координатор не считал вручную.
3. **B1.4** — список участников в Studio.
4. **B1.6** — восстановление доступа: нужен выбор почтового провайдера (#172).

Игровые пакеты из `docs/roadmap/spec.md` — тест навыка, карта в базе, новые персонажи — **на паузе** до итогов первых двух недель беты.
