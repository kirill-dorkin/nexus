# Первая волна беты: план на 4 недели

Правила и норма — в `docs/roadmap/beta-launch.md` (#207), разделы 3–5. Каждая неделя:
- **3 учебных дня**;
- **5 новых уроков** — все обязательные задания урока пройдены впервые;
- **1 практическая работа**;
- **1 отзыв**.

Это примерно 2–4 часа в неделю.

Сайт: <https://nexus-lake-nine-17.vercel.app>. Все ссылки ниже ведут на опубликованные уроки. В каждом уроке есть обязательные квизы, поэтому урок засчитывается проверкой на сервере, а не просмотром.

**Две траектории.**
- **Новичок** — HTML.
- **Знает HTML** — CSS.

Координатор выбирает траекторию по короткому вопросу в анкете (`texts.md`, «Приглашение»).

**Практика 1 — «Моя первая страница»** (ручная проверка координатором). Сохранить у себя файл `index.html`, открыть в браузере, прислать файл координатору. Критерии:
1. Файл открывается в браузере без ошибок.
2. Есть заголовок `h1` со своим текстом, не «Моя первая страница».
3. Есть хотя бы два абзаца `p` о себе или своей цели.
4. Ученик может объяснить, что делает каждый тег.

**Практика 2 — «Страница о себе»** (ручная). Критерии:
1. Полный каркас: `<!doctype html>`, `<html lang="ru">`, `head` с `<meta charset="utf-8">` и `title`, `body`.
2. Иерархия заголовков без пропусков: один `h1`, разделы `h2`.
3. Хотя бы один спецсимвол через сущность, например `&copy;` или `&nbsp;`.
4. Хотя бы один глобальный атрибут по делу: `id`, `title` или `lang` у фразы на другом языке.

**Практика 3 — «Заметка с правильной семантикой»** (ручная). Критерии:
1. Есть `strong` и `em`, и они использованы по смыслу, а не ради жирного или курсива.
2. Есть пример кода в `code` и сочетание клавиш в `kbd`.
3. Есть цитата `blockquote` с источником `cite`.
4. Есть контакты в `address`.
5. Нет `div` и `span` там, где есть смысловой тег.

## Если ученик идёт быстрее или медленнее

- **Быстрее.** Можно идти дальше по курсу. Норма — минимум, а не потолок. Следующие задания с автопроверкой:
  - HTML: фотогалерея (урок 32), форма регистрации (урок 46);
  - CSS: дальше по курсу.
- **Медленнее.** Координатор по согласованию снижает норму на следующую неделю (раздел 3 `beta-launch.md`) и фиксирует причину в журнале.
- **Файловая практика с телефона неудобна.** В приглашении заранее сказано, что для практики нужен компьютер.
