Версия 1, 2026-11-05. Сводит вместе всё, что осталось:

## 1. Где проект сейчас

**Работает в продакшене:**
- Вход: пароль, Google, GitHub. Защита от перебора паролей, заголовки безопасности.
- Курсы HTML, CSS, JavaScript, SQL — 289 уроков, около 600 квизов, 351 задача практики в браузере, 13 домашних заданий с серверной проверкой.
- Персонажи: ростер, профили, ветки навыков, срок навыка (`skill-freshness@1` на сервере), задания дня, серия, уровень игрока, сцены сезона 1, карта города, «Скоро в городе».
- Studio: черновик, JSON, предпросмотр, публикация.
- Выкладка: изменения базы применяются сами перед каждой выкладкой (ADR-0079). Проверка продакшена ждёт свой релиз.

**Есть в коде, но выключено или без интерфейса:**
- оплата Paddle — расчёты некому выполнять;
- грейдер — исполнение кода учеников;
- GitHub-проекты;
- когорты, Guided Build, рекомендации, готовность к следующему курсу.

**Базы данных уже готовы, кода нет:**
- банки вопросов и выдачи тестов навыков (000050);
- карта навыков в базе (000051).

## 3. Порядок работ

Фазы идут по порядку, а внутри фазы потоки параллельны — до 4 сессий, тяжёлые проверки через общую блокировку.

### Фаза 1 — «прокачка по-настоящему», ~1 неделя

- **Поток 1:** A1 тест навыка, сразу с банком HTML (часть B2).
- **Поток 2:** A3 карта в базе, затем A2 замок опор.
- **Поток 3:** B2 банки CSS и SQL.
- **Поток 4:** A7 достижения, публикация ПК и Браузера (B1).

Итог: навык засчитывается только тестом, забывается и вспоминается, опоры проверяет сервер.

### Фаза 2 — «можно пускать людей», ~1–2 недели

- **Поток 1:** C1 хостинг фоновых процессов и C2 читатель outbox.
- **Поток 2:** D1 письма и сброс пароля, D4 удаление аккаунта.
- **Поток 3:** E1–E5 испытатели.
- **Поток 4:** B2 банки JS, ПК и Браузера.
- **Владелец:** D2 тексты, D3 решение по 152-ФЗ.

Итог: первая волна испытателей с нормой и отчётами.

### Фаза 3 — «деньги», ~2 недели

- **Поток 1:** F1–F4 подписка «Искатель» ($50).
- **Поток 2:** C5 staging, C6 резервные копии, C7 оповещения.
- **Поток 3:** A4 главная-карта, A5 иллюстрации, A6 рои Бага.
- **Поток 4:** G1–G2 аналитика.

Итог: первые платящие ученики.

### Фаза 4 — «практика и сезон 2», ~3 недели

- **Поток 1:** C3 грейдер в продакшен.
- **Поток 2:** C4 SQL-песочница, затем B3 бои JS и SQL.
- **Потоки 3–4:** B4 сезон 2 (Git, Терминал, Сеть, TypeScript), B6 сцены.

### Фаза 5 — «люди и фреймворки», ~4–6 недель

- F6: уровни с наставниками — только когда у владельца есть люди.
- B5: сезон 3 (React, Next.js, Vue, Nuxt, Angular).
- A8: Studio.
- C8: нагрузочная проверка.

**Всего:** около 11–14 недель до полного продукта с подпиской, испытателями, грейдером и двумя новыми сезонами. Первые платящие ученики — примерно через 4–5 недель, после фазы 3.

## 5. Риски

| Риск | Что делаем |

| Объём контента: тысячи вопросов и десятки персонажей | Конвейер с тестами покрытия; параллельные сессии; владелец проверяет выборочно |

| 152-ФЗ и платежи из РФ | Решение владельца до фазы 3; без него не принимаем деньги от россиян |
| Автоматические изменения базы при слиянии | Только аддитивные изменения; staging (C5); проверка восстановления (C6) |
| Исполнение кода учеников (грейдер) | Отдельная проверка безопасности и изоляция gVisor, включение только по решению |
| Минуты GitHub Actions | Документация без CI, отмена устаревших прогонов, тяжёлые проверки локально; бюджет $20 |

## 6. Что агент делает без вопросов, а что нет

**Без вопросов:** код, тесты, ADR, контент, миграции (они применяются сами), свои зелёные PR, проверка продакшена.

**Только с владельцем:**
- публикация курсов (нужен пароль владельца, его агент не использует);
- включение оплаты и цен;
- грейдер в продакшене;
- юридические тексты;
- выбор провайдеров;
- замена главной;
- удаление данных.
