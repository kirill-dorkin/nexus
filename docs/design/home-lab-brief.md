# Whole homepage preview

## Scope

Persuade mode; `/ui/home-lab`, isolated from `/`. Rebuild a complete public
homepage, with actual catalog and Blog content, in one consistent visual system.
The user asked to proceed with the previously proposed rebuild; their original
brief and String Lab reference answer purpose, content, constraints and direction.
No new interview or concept tournament is needed. Code-first is explicitly
required by the original task; no image of a page is an implementation.

## Direction contract

THESIS: Learning means material, action and feedback. The entire page makes
that mechanism visible and leads to choosing a real course.

OWN-WORLD: Onest, precise Radix spacing/controls, quiet pale accent surfaces,
opaque plum instructional code and one readable live document. Existing theme
and accent tokens retain authority over colour.

STORY: Understand the platform, try a tiny labelled HTML example, choose a
course, read a genuine introductory article, resolve entry questions.

FIRST VIEWPORT: A compact session-aware header, a 56 px two-line thesis and
catalog CTA above one full-width lesson workbench. Material and live result
occupy the same contiguous scene. No decorative portal or mock dashboard.

FORM: User-pinned String Lab instructional language, translated into a complete
web discovery page. Course cover and copy share one two-column feature below;
Blog and FAQ use the same type, corner and spacing rules. No roll: pinned brief.

SIGNATURE: Change a real heading and see the rendered document update; check a
question and get local feedback. Motion is a short response to that action,
removed by reduced motion; no autoplay or continuous glow.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
