Из чего состоит компьютер

Компьютер — это система взаимосвязанных компонентов. Чтобы разобраться в его работе, начнём с того, какую задачу выполняет каждый из них.

Что делает процессор

Процессор выполняет инструкции программ. Оперативная память помогает быстро хранить данные, с которыми компьютер работает прямо сейчас, а SSD сохраняет файлы после выключения.

Запомните главное: оперативная память и постоянное хранилище решают разные задачи.
