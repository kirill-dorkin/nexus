# Курс «HTML с нуля: полный курс»

Файл для импорта: [`html-track.manifest.json`](html-track.manifest.json) — 69 атомарных уроков (≈14,5 часа), 171 задание с автоматической проверкой, 7 проектов. Один урок — один навык.

Исходники контента — в [`html-course/`](html-course/), порядок уроков задаёт [`build.mjs`](html-course/build.mjs). JSON не правят руками, а пересобирают:

```bash
node docs/examples/html-course/build.mjs
npx vitest run packages/contracts/src/html-track-manifest.test.ts
```

## Программа

0. **Старт с нуля** — как устроен веб, инструменты (браузер, VS Code, Emmet, Live Server), первая страница на своём компьютере, как искать ответы.
1. **Основы** — что такое HTML, каркас, DOM и DevTools, заголовки, пробелы и спецсимволы, глобальные атрибуты, блочные и строчные элементы.
2. **Текст** — выделение, строчная семантика, код, цитаты и адреса, списки, списки определений, языки, направление и ruby. *Мини-проект: рецепт.*
3. **Ссылки** — ссылки и якоря, пути к файлам, download и rel.
4. **Медиа** — изображения, форматы, адаптивные изображения, видео, аудио и субтитры, iframe, SVG и MathML, script/template/canvas, карты-изображения и object. *Мини-проект: фотогалерея.*
5. **Таблицы** — основы и сложные таблицы.
6. **Формы** — отправка, подписи, типы полей, флажки и переключатели, select и datalist, кнопки, файлы, проверка, удобство, output/progress/meter, продвинутые возможности. *Мини-проект: регистрация.*
7. **Структура** — семантика, article/section/aside/search, details, dialog и popover. *Проект 1: визитка.*
8. **Head** — метаданные, превью и иконки, подключение ресурсов, style/base/meta, безопасность, структурированные данные. *Проект 2: лендинг.*
9. **HTML и JavaScript** — события и DOM, редактирование и перетаскивание, свои элементы и Shadow DOM.
10. **Доступность** — основы, клавиатура и фокус, ARIA. *Проект 3: статья.*
11. **Качество** — валидатор, устаревшие элементы, справочник всех элементов. *Финальный проект: многостраничное портфолио.*

В каждом уроке: объяснение, примеры в блоках ```html (кнопка «Попробовать» открывает песочницу в браузере ученика), частые ошибки, задание, обязательный вопрос с проверкой и ссылка на MDN.

## Правила авторинга

- Markdown уроков рендерится без GFM: не используйте таблицы с `|` и чекбоксы `- [ ]`.
- Сырой HTML в Markdown вырезается: теги в тексте пишите в обратных кавычках. В вопросах это делает `lib.mjs` автоматически.
- Внешние медиа в примерах — только надёжные открытые источники (picsum.photos, медиа MDN с лицензией CC0).

## Как опубликовать

Одной командой (оператору, с локальным чекпоинтом migrator):

```bash
node scripts/launch-course.mjs                                   # первая публикация
node scripts/launch-course.mjs --new-version --offering-slug <адрес>  # новая версия
```

Доступ (Offering) привязан к конкретной версии, поэтому новая версия получает новый адрес, а старый доступ скрывается.

Вручную:

1. Studio → организация → «Создать курс» → «JSON».
2. Загрузите файл → «Проверить документ» → «Сохранить черновик» → «Опубликовать».
3. На странице доступа курса создайте Offering и подтвердите публичную видимость.
4. В настройках организации включите самостоятельное вступление, чтобы ученики начинали курс одной кнопкой.
