# Курс «HTML: полный курс»

Файл для импорта: [`html-track.manifest.json`](html-track.manifest.json) — 50 атомарных уроков (≈10,5 часа), 134 задания с автоматической проверкой, 4 проекта. Один урок — один навык.

Исходники контента — в [`html-course/`](html-course/): по файлу на модуль. JSON не правят руками, а пересобирают:

```bash
node docs/examples/html-course/build.mjs
npx vitest run packages/contracts/src/html-track-manifest.test.ts
```

## Программа

1. **Основы** — что такое HTML, каркас документа, DOM и DevTools, заголовки и абзацы, пробелы и спецсимволы, глобальные атрибуты.
2. **Текст** — смысловое выделение, строчная семантика, код и клавиши, цитаты и адреса, списки, списки определений.
3. **Ссылки** — ссылки и якоря, пути к файлам, download и rel.
4. **Медиа** — изображения, форматы, адаптивные изображения, видео, аудио и субтитры, iframe, SVG и MathML, script/noscript/template/canvas.
5. **Таблицы** — основы и сложные таблицы.
6. **Формы** — отправка, подписи, типы полей, флажки и переключатели, select и datalist, textarea и кнопки, загрузка файлов, встроенная проверка, удобство, output/progress/meter.
7. **Структура** — семантика страницы, article/section/aside/search, details/summary, dialog и popover.
8. **Head** — метаданные, превью в соцсетях и иконки, подключение ресурсов.
9. **Доступность** — основы, клавиатура и фокус, ARIA.
10. **Качество и проекты** — валидатор и частые ошибки; визитка, лендинг, статья, многостраничное портфолио.

В каждом уроке: объяснение, примеры в блоках ```html (кнопка «Попробовать» открывает песочницу прямо в браузере ученика), частые ошибки, задание, обязательный вопрос с проверкой и ссылка на MDN.

## Правила авторинга

- Markdown уроков рендерится без GFM: не используйте таблицы с `|` и чекбоксы `- [ ]`.
- Сырой HTML в Markdown вырезается: теги в тексте пишите в обратных кавычках. В вопросах это делает `lib.mjs` автоматически.
- Внешние медиа в примерах — только надёжные открытые источники (picsum.photos, медиа MDN с лицензией CC0).

## Как опубликовать

1. Studio → организация → «Создать курс» → «JSON».
2. Загрузите файл → «Проверить документ» → «Сохранить черновик» → «Опубликовать».
3. На странице доступа курса создайте Offering и подтвердите публичную видимость.
4. В настройках организации включите самостоятельное вступление, чтобы ученики начинали курс одной кнопкой.
