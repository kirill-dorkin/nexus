# Курс «HTML с нуля»

Файл для импорта: [`html-track.manifest.json`](html-track.manifest.json) — 70 атомарных уроков (≈14,7 часа), 174 задания с автоматической проверкой, 7 проектов. Один урок — один навык.

Исходники контента — в [`html-course/`](html-course/), порядок уроков задаёт [`build.mjs`](html-course/build.mjs). JSON не правят руками, а пересобирают:

```bash
node docs/examples/html-course/build.mjs
npx vitest run packages/contracts/src/html-track-manifest.test.ts
```

## Программа

0. **Старт с нуля** — как устроен веб, инструменты (браузер, VS Code, Emmet, Live Server), первая страница на своём компьютере, как искать ответы.
1. **Основы** — что такое HTML, каркас, DOM и DevTools, заголовки, пробелы и спецсимволы, глобальные атрибуты, блочные и строчные элементы.
2. **Текст** — выделение, строчная семантика, код, цитаты и адреса, списки, списки определений, языки, направление и ruby. *Мини-проект: рецепт.*
3. **Ссылки** — ссылки и якоря, пути к файлам, download и rel.
4. **Медиа** — изображения, форматы, адаптивные изображения, видео, аудио и субтитры, iframe, SVG и MathML, script/template/canvas, карты-изображения и object. *Мини-проект: фотогалерея.*
5. **Таблицы** — основы и сложные таблицы.
6. **Формы** — отправка, подписи, типы полей, флажки и переключатели, select и datalist, кнопки, файлы, проверка, удобство, output/progress/meter, продвинутые возможности. *Мини-проект: регистрация.*
7. **Структура** — семантика, article/section/aside/search, details, dialog и popover. *Проект 1: визитка.*
8. **Head** — метаданные, превью и иконки, подключение ресурсов, style/base/meta, безопасность, структурированные данные. *Проект 2: лендинг.*
9. **HTML и JavaScript** — события и DOM, редактирование и перетаскивание, свои элементы и Shadow DOM.
10. **Доступность** — основы, клавиатура и фокус, ARIA. *Проект 3: статья.*
11. **Качество** — самопроверка инструментами браузера, устаревшие элементы, новинки HTML 2024–2025, справочник всех элементов. *Финальный проект: многостраничное портфолио.*

В каждом уроке: объяснение, примеры в блоках ```html (кнопка «Попробовать» открывает песочницу в браузере ученика), частые ошибки, задание, обязательный вопрос с проверкой и ссылка на MDN.


## Задания с файлами

В конце каждого проекта — необязательное домашнее задание «скачай и сдай» (ADR-0073), всего 7: ученик скачивает заготовку, делает задание в своём редакторе и загружает файлы, сервер проверяет разметку и стили и показывает, что исправить. Задания описаны в [`html-course/assignments.mjs`](html-course/assignments.mjs); тест `packages/checks/src/course-assignments.test.ts` проверяет, что эталон проходит все проверки, а заготовка — нет. На прогресс курса задания не влияют: они необязательные.

## Полнота

Курс покрывает **все элементы и атрибуты** из индекса HTML Living Standard. Снимок индекса лежит в [`html-course/spec-index.json`](html-course/spec-index.json), тест падает, если что-то из него не встречается в уроках. Обновить снимок:


## Правила авторинга

- Markdown уроков рендерится без GFM: не используйте таблицы с `|` и чекбоксы `- [ ]`.
- Сырой HTML в Markdown вырезается: теги в тексте пишите в обратных кавычках. В вопросах это делает `lib.mjs` автоматически.
- **Формат урока — сцены и карточки.** Тексты уроков лежат в `html-course/stories/*.mjs` (урок → части) и заменяют старую прозу из `m*.mjs`/`x*.mjs` (там остаются названия, навыки и тесты). Порядок: сцена-переписка `scene(...)` с персонажами-инструментами (Бро — браузер, Ника — наставница, Лев — слушает сайты скринридером, Вредный Скрипт), затем карточки `card(имя, заголовок, что это, зачем, код, { show })`, затем «Ваш ход» с заданиями. Никаких абзацев-вступлений: одна мысль — одна карточка.
- **Плашка урока** — `html-course/stories/recaps.mjs`: одна нейтральная фраза «Сейчас» о том, что делает урок. Сквозного сюжета нет (ADR-0066), героев плашки `build.mjs` берёт из сцен урока. Правило Ники `rule(...)` — это реплика в чате, а не цитата.
- **Примеры и задания** — у каждого урока свой пример по теме (путеводитель, рецепт, галерея, форма записи, портфолио). Герои — только инструменты: Бро (браузер), Ника (наставница), Лев (скринридер), Вредный Скрипт. Курс объясняет всё сам и не отправляет учиться на другие сайты — это проверяет тест-контракт.
- **Главы** — задаются в `build.mjs` (список `chapters`): все уроки модулей главы получают поле `chapter`. На странице курса это разделы программы, в уроке — сворачиваемые группы.
- **Проекты** — `html-course/challenges-projects.mjs`: пошаговая сборка одной страницы (3–4 шага), каждый шаг начинается с результата предыдущего.
- **Длительность урока** считается из содержимого (`estimateMinutes` в `lib.mjs`): чтение, карточки, задания, тесты. Не пишите минуты руками.
- **Обращение к ученику — на «ты»** (как у героев). Тексты на страницах-примерах для их посетителей остаются на «вы».
- **Задания (механика)** — в каждом уроке. Они лежат в `html-course/challenges*.mjs` (урок → список). Задание с `at` встаёт в конец указанного раздела `##`, остальные заменяют раздел «Практика». Проверки декларативные: CSS-селектор (`selector` с `text`, `attr`, `value`, `count`, `max`, `absent`) или фрагмент исходника (`contains`). Тест требует, чтобы решение проходило все проверки, а стартовый код — нет.
- Схемы — блок ```` ```diagram ```` через `diagram({ kind: "url" | "tree" | "flow" | "dom", … })`.
- Анимации — `demo({ kind: "typing", title, input, key, output, caption, parts })`: **одна анимация на блок**. `parts` разбирает сокращение на цветные метки (их тексты вместе должны давать `input`). Анимация стартует, когда блок виден, проигрывается один раз и останавливается на результате.
- Адреса уроков — английские слаги (`how-browsers-read-html`): они видны в ссылке `/courses/html/<урок>`. Не меняйте слаг опубликованного урока без причины.
- Внешние медиа в примерах — только надёжные открытые источники (picsum.photos и открытые CC0-медиа).

## Как опубликовать

Одной командой (оператору, с локальным чекпоинтом migrator):

```bash
node scripts/launch-course.mjs                                   # первая публикация
node scripts/launch-course.mjs --new-version                     # новая версия
```

Ученики всегда открывают курс по постоянному адресу `/courses/html` (ADR-0061). При новой версии существующий доступ переводится на неё (ADR-0062): запись на курс и пройденные задания у учеников сохраняются.

Вручную:

1. Studio → организация → «Создать курс» → «JSON».
2. Загрузите файл → «Проверить документ» → «Сохранить черновик» → «Опубликовать».
3. На странице доступа курса создайте Offering и подтвердите публичную видимость.
4. В настройках организации включите самостоятельное вступление, чтобы ученики начинали курс одной кнопкой.
