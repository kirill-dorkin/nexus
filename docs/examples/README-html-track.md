# Трек «HTML с нуля»

Файл: [`html-track.manifest.json`](html-track.manifest.json). 11 атомарных уроков (≈2 часа): один урок — один навык, 23 задания с автоматической проверкой, финальный проект-визитка.

| # | Урок | Навык |
|---|---|---|
| 1 | Что такое HTML | теги, элементы, атрибуты |
| 2 | Каркас HTML-документа | doctype, head, body, кодировка |
| 3 | Заголовки и абзацы | h1–h6, p, иерархия |
| 4 | Выделение текста по смыслу | strong, em, br, мнемоники |
| 5 | Ссылки | a, href, якоря, почта |
| 6 | Изображения | img, alt, размеры, figure |
| 7 | Списки | ul, ol, li, вложенность |
| 8 | Таблицы | table, th, td, caption |
| 9 | Формы | form, label, input, radio |
| 10 | Семантическая структура | header, nav, main, article |
| 11 | Проект: страница-визитка | всё вместе + чек-лист |

Каждый пример в блоке ```html открывается в песочнице кнопкой «Попробовать»: код выполняется только в браузере ученика.

## Как опубликовать

1. Studio → организация → «Создать курс» → «JSON».
2. Загрузите файл → «Проверить документ» → «Сохранить черновик» → «Опубликовать».
3. Откройте страницу доступа курса: создайте Offering и подтвердите публичную видимость.
4. В настройках организации включите самостоятельное вступление, чтобы ученики могли начать курс одной кнопкой.

Тексты можно править в Studio вручную или в JSON. Проверку схемы и ключей ответов выполняет `packages/contracts/src/html-track-manifest.test.ts`.
