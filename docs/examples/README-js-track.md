# Курс «JavaScript с нуля: живой сайт кофейни»

Файл для импорта: [`js-track.manifest.json`](js-track.manifest.json) — 24 главы, 114 уроков (≈17 часов), 523 карточки, 129 заданий с запуском кода и 216 проверяемых активностей. Курс покрывает **весь** ECMAScript 2025: каждую синтаксическую конструкцию и каждый метод каждого встроенного объекта.

Это курс-история. Ученик оживляет сайт кофейни «Зерно» вместе с хозяйкой Мартой, браузером Бро и наставницей Никой, а Вредный Скрипт мешает. Код в примерах и заданиях выполняется прямо в браузере ученика. Песочница описана в [ADR-0064](../adr/0064-runnable-javascript-practice.md).

Исходники — в [`js-course/`](js-course/), порядок глав задаёт [`build.mjs`](js-course/build.mjs). JSON не правят руками, а пересобирают:

```bash
node docs/examples/js-course/build.mjs
npx vitest run packages/contracts/src/js-track-manifest.test.ts apps/web/src/components/learning/course-challenges.test.ts
```

## Программа

1. **Старт JavaScript**: что такое JS, консоль, let и const, типы, ошибки и комментарии.
2. **Значения и операторы**: арифметика, строки и шаблоны, сравнение, логика (`&&`, `||`, `??`, `?.`), преобразование типов.
3. **Условия и циклы**: if/else, тернарный оператор и switch, for и while, for…of, break и continue. *Проект: счёт со скидкой.*
4. **Функции**: объявление и return, параметры по умолчанию и rest, стрелочные функции, замыкания, колбэки.
5. **Массивы**: методы списков, map и filter, find/some/every, reduce, сортировка и куски, деструктуризация и spread.
6. **Объекты**: свойства, методы и this, перебор, JSON, классы.
7. **DOM**: поиск элементов, текст и разметка (и почему `textContent`), классы и атрибуты, создание элементов, навигация.
8. **События**: клик, объект события, ввод, клавиатура, делегирование. *Проект: живая корзина.*
9. **Формы**: submit, проверка с доступными ошибками, FormData.
10. **Асинхронность**: таймеры, промисы, async/await, fetch, состояния загрузки. *Проект: меню с сервера.*
11. **Хранение и финал**: localStorage, даты и Intl, Math, модули и отладка. *Финальный проект: живое «Зерно».*

**Часть 2. JavaScript полностью.** Справочная глубина: каждая возможность языка разобрана отдельной карточкой с живым примером.

12. **Синтаксис полностью**: примитивы и ссылки, всплытие и строгий режим, все операторы (побитовые, логическое присваивание, void, запятая), литералы, классы целиком, итераторы и генераторы, асинхронные итераторы, модули, цикл событий.
13. **Объекты и функции изнутри**: прототипы, собственные свойства, дескрипторы, заморозка, преобразование в примитивы, call/apply/bind, глобальные функции.
14. **Строки полностью**: символы и коды, поиск, преобразования, Юникод и сравнение.
15. **Числа и Math полностью**: границы чисел, форматирование, BigInt, все функции Math.
16. **Массивы и итераторы полностью**: создание, поиск с конца, копии с изменением, помощники итераторов.
17. **Коллекции**: Map, Set и операции над множествами, WeakMap, WeakSet, WeakRef, FinalizationRegistry.
18. **Регулярные выражения**: синтаксис, все флаги, группы, просмотр вперёд и назад, RegExp.escape.
19. **Symbol, Proxy и Reflect**: символы, встроенные символы, перехват операций.
20. **Ошибки, ресурсы и промисы**: все виды ошибок, `using` и DisposableStack, все комбинаторы промисов, JSON целиком.
21. **Даты полностью**: метки времени, все части даты (местные и UTC), форматы вывода.
22. **Intl полностью**: числа и склонения, даты, «назад», длительности, списки, названия, сравнение, сегментация, Intl.Locale.
23. **Бинарные данные и общая память**: ArrayBuffer, все типизированные массивы, DataView, SharedArrayBuffer и Atomics.
24. **Устаревшее**: приложение B стандарта — как читать старый код и чем его заменить.

## Как работает практика

Задание с `lang: "js"` устроено так:
- ученик редактирует JavaScript, который запускается поверх фиксированной разметки `page`;
- проверки `run(выражение)` вычисляются после запуска и могут использовать `await` и `wait(ms)`;
- проверки `out(текст)` ищут текст в консоли;
- проверки `has(фрагмент)` смотрят в исходный код.

Учебный сервер работает внутри песочницы, без сети:

| Запрос | Ответ |
| --- | --- |
| `GET /api/menu` | шесть позиций |
| `GET /api/menu/:id` | одна позиция |
| `POST /api/orders` | эхо заказа с `id: 1042` |

Тесты запускают каждое решение, каждый стартовый код и каждый пример из карточек в happy-dom. Решение должно пройти все проверки, стартовый код должен не пройти хотя бы одну, а пример не должен падать с ошибкой.

## Полнота

[`js-course/spec-index.json`](js-course/spec-index.json) — снимок всего языка, 719 пунктов:
- синтаксис;
- все члены стандартных встроенных объектов, прочитанные из движка;
- устаревшее приложение B.

Каждая карточка перечисляет в `covers` пункты, которые она объясняет: до четырёх, у устаревшего до восьми. Тест-контракт требует, чтобы каждый пункт был покрыт ровно один раз.

Обновить снимок под новую версию языка:

```bash
node docs/examples/js-course/update-spec-index.mjs
```

Тест сразу покажет, что появилось в языке и пока не объяснено.
