# Курс «JavaScript с нуля: живой сайт кофейни»

Файл для импорта: [`js-track.manifest.json`](js-track.manifest.json) — 56 уроков (≈8,5 часа), 115 заданий с автоматической проверкой, 4 проекта.

Это курс-история. Ученик оживляет сайт кофейни «Зерно» вместе с хозяйкой Мартой, браузером Бро и наставницей Никой, а Вредный Скрипт мешает. Код в примерах и заданиях выполняется прямо в браузере ученика. Песочница описана в [ADR-0064](../adr/0064-runnable-javascript-practice.md).

Исходники — в [`js-course/`](js-course/), порядок глав задаёт [`build.mjs`](js-course/build.mjs). JSON не правят руками, а пересобирают:

```bash
node docs/examples/js-course/build.mjs
npx vitest run packages/contracts/src/js-track-manifest.test.ts apps/web/src/components/learning/course-challenges.test.ts
```

## Программа

1. **Старт JavaScript**: что такое JS, консоль, let и const, типы, ошибки и комментарии.
2. **Значения и операторы**: арифметика, строки и шаблоны, сравнение, логика (`&&`, `||`, `??`, `?.`), преобразование типов.
3. **Условия и циклы**: if/else, тернарный оператор и switch, for и while, for…of, break и continue. *Проект: счёт со скидкой.*
4. **Функции**: объявление и return, параметры по умолчанию и rest, стрелочные функции, замыкания, колбэки.
5. **Массивы**: методы списков, map и filter, find/some/every, reduce, сортировка и куски, деструктуризация и spread.
6. **Объекты**: свойства, методы и this, перебор, JSON, классы.
7. **DOM**: поиск элементов, текст и разметка (и почему `textContent`), классы и атрибуты, создание элементов, навигация.
8. **События**: клик, объект события, ввод, клавиатура, делегирование. *Проект: живая корзина.*
9. **Формы**: submit, проверка с доступными ошибками, FormData.
10. **Асинхронность**: таймеры, промисы, async/await, fetch, состояния загрузки. *Проект: меню с сервера.*
11. **Хранение и финал**: localStorage, даты и Intl, Math, модули и отладка. *Финальный проект: живое «Зерно».*

## Как работает практика

Задание с `lang: "js"` устроено так:
- ученик редактирует JavaScript, который запускается поверх фиксированной разметки `page`;
- проверки `run(выражение)` вычисляются после запуска и могут использовать `await` и `wait(ms)`;
- проверки `out(текст)` ищут текст в консоли;
- проверки `has(фрагмент)` смотрят в исходный код.

Учебный сервер работает внутри песочницы, без сети:

| Запрос | Ответ |
| --- | --- |
| `GET /api/menu` | шесть позиций |
| `GET /api/menu/:id` | одна позиция |
| `POST /api/orders` | эхо заказа с `id: 1042` |

Тесты запускают каждое решение, каждый стартовый код и каждый пример из карточек в happy-dom. Решение должно пройти все проверки, стартовый код должен не пройти хотя бы одну, а пример не должен падать с ошибкой.

## Полнота

[`js-course/js-index.json`](js-course/js-index.json) перечисляет ключевые слова, операторы, методы, объекты, события, типы, функции и значения, которые объясняет курс. Тест-контракт падает в двух случаях:
- у пункта из списка нет своей карточки;
- карточка повторяется в другом уроке.
