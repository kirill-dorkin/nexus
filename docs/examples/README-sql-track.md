# Курс «SQL с нуля: данные кофейни»

Файл для импорта: [`sql-track.manifest.json`](sql-track.manifest.json). В курсе 52 урока (≈7,4 часа), 59 заданий с автоматической проверкой и 104 вопроса.

Это курс-история. Заказы «Зерна» живут в тетрадках, а маркетологу Даше нужны цифры. Ученик переносит всё в PostgreSQL и учится задавать данным вопросы. Ему помогают хозяйка Марта, маркетолог Даша, база данных Слон и наставница Ника.

Все примеры и задания выполняются на настоящем PostgreSQL прямо в браузере ученика (PGlite в Web Worker, [ADR-0065](../adr/0065-sql-practice-in-browser-postgres.md)). Каждый запуск начинается с чистой учебной базы «Зерно» ([`zerno-db.ts`](../../apps/web/src/components/learning/sql/zerno-db.ts)). В ней 7 таблиц: категории, товары, гости, сотрудники, заказы, позиции заказов, отзывы.

Исходники лежат в [`sql-course/`](sql-course/), порядок глав задаёт [`build.mjs`](sql-course/build.mjs). JSON не правят руками, его пересобирают:

```bash
node docs/examples/sql-course/build.mjs
npx vitest run packages/contracts/src/sql-track-manifest.test.ts apps/web/src/components/learning/course-challenges.test.ts
```

## Программа

1. **Старт SQL**: база данных и таблицы, SELECT и FROM, выражения и AS, DISTINCT, комментарии и стиль.
2. **Фильтры**: WHERE и сравнение, AND/OR/NOT, IN и BETWEEN, LIKE и ILIKE, NULL.
3. **Сортировка и порции**: ORDER BY, LIMIT и OFFSET.
4. **Функции и выражения**: числа, строки, CASE, COALESCE и NULLIF, даты и время, типы и приведение.
5. **Агрегаты и группы**: COUNT/SUM/AVG/MIN/MAX, GROUP BY, HAVING и порядок выполнения, FILTER и string_agg.
6. **Соединения таблиц**: ключи и связи, JOIN, LEFT JOIN, RIGHT/FULL/CROSS, self join, цепочки соединений.
7. **Подзапросы и множества**: подзапросы, EXISTS/ANY/ALL, производные и коррелированные подзапросы, WITH, UNION/INTERSECT/EXCEPT, WITH RECURSIVE.
8. **Изменение данных**: INSERT, UPDATE, DELETE и TRUNCATE, RETURNING, ON CONFLICT, транзакции.
9. **Свои таблицы**: CREATE TABLE и типы, ограничения, внешние ключи, ALTER/DROP, нормализация.
10. **Аналитика**: оконные функции, нарастающие итоги и LAG/LEAD, представления, JSON.
11. **Скорость и безопасность**: индексы и EXPLAIN, SQL-инъекции и права. *Итоговый проект: отчёт для Марты.*

В каждом уроке есть:
- сцена с персонажами;
- концепт-карточки «Что это / Зачем / Как». Пример в карточке выполняется, и под ним видна таблица, которую вернула база;
- задание в SQL-редакторе с живой проверкой;
- вопросы.

## Полнота

[`sql-course/sql-index.json`](sql-course/sql-index.json) перечисляет все команды, части запроса, ключевые слова, операторы, функции, типы и ограничения, которые объясняет курс. Тест падает в двух случаях:
- у пункта из списка нет своей карточки;
- карточка повторяется в другом уроке.

## Правила авторинга

- Карточки пишутся через `stmt`, `clause`, `kw`, `op`, `fn`, `type`, `cons` и `idea` из [`sql-course/kit.mjs`](sql-course/kit.mjs). Пример (`how`) запускается на чистой базе, поэтому должен выполняться без ошибки; это проверяет тест. Пример, который нельзя запускать (роли, `$1`), помечают `still`.
- Проверки задания:
  - `rows(запрос, подпись, { ordered, names })`: последний результат ученика совпадает с результатом эталонного запроса. Числа сравниваются по значению.
  - `holds(запрос, подпись)`: запрос после кода ученика возвращает `true`. Подходит для INSERT/UPDATE/DDL.
  - `src(фрагмент, подпись)`: фрагмент есть в коде ученика.
- Решение каждого задания проходит все проверки, а стартовый код хотя бы одну не проходит. Это проверяет тест.
- Если поменять данные в `zerno-db.ts`, изменятся ожидаемые ответы. После правки пересобери курс и прогони тесты.
