# Курс «CSS с нуля: красивый сайт кофейни»

Файл для импорта: [`css-track.manifest.json`](css-track.manifest.json) — 53 урока (≈9 часов), 105 заданий с автоматической проверкой, 5 проектов. Курс-история: ученик делает сайт кофейни «Зерно» красивым вместе с хозяйкой Мартой, дизайнером Соней, верстальщиком Бро, наставницей Никой и ветераном Лёвой.

Исходники — в [`css-course/`](css-course/), порядок глав задаёт [`build.mjs`](css-course/build.mjs). JSON не правят руками, а пересобирают:

```bash
node docs/examples/css-course/build.mjs
npx vitest run packages/contracts/src/css-track-manifest.test.ts apps/web/src/components/learning/course-challenges.test.ts
```

## Программа

1. **Старт CSS**: что такое CSS, подключение, базовые селекторы, каскад и специфичность, наследование, стили в DevTools.
2. **Цвет и текст**: цвета и функции цвета, единицы, шрифты, оформление текста, списки, ссылки и состояния. *Проект: типографика меню.*
3. **Блочная модель**: content, padding, border, margin; box-sizing, рамки и outline, фоны, тени и эффекты, display и overflow. *Проект: карточка напитка.*
4. **Селекторы**: селекторы атрибутов, комбинаторы, псевдоклассы, псевдоэлементы.
5. **Flexbox**: основы, выравнивание, гибкость элементов. *Проект: шапка сайта.*
6. **Grid**: колонки и строки, расстановка и области, автоматическая сетка, выравнивание и subgrid. *Проект: меню-сетка.*
7. **Позиционирование**: position, z-index и контекст наложения, float и колонки текста.
8. **Адаптивность**: @media и mobile-first, медиа-характеристики (тёмная тема, движение, мышь), @container. *Проект: адаптивная главная.*
9. **Анимации**: transition, transform, @keyframes, прокрутка и scroll-snap.
10. **Современный CSS**: переменные и @property, вложенность, @layer и @scope, логические свойства, color-scheme и light-dark(), формы и интерфейс, счётчики.
11. **Доступность и качество**: доступный CSS, производительность (content-visibility, contain) и clip-path, печать и таблицы. *Финальный проект: сайт «Зерна» целиком.*

В каждом уроке есть:
- сцена с персонажами;
- концепт-карточки «Что это / Зачем / Как» с живым превью;
- задание в редакторе с проверкой CSS;
- вопросы.

## Полнота

[`css-course/css-index.json`](css-course/css-index.json) перечисляет все свойства, селекторы, @-правила, функции и значения, которые объясняет курс. Тест падает в двух случаях:
- у пункта из списка нет своей карточки;
- карточка повторяется в другом уроке.

## Правила авторинга

- Карточки пишутся через `prop`, `sel`, `at`, `fn`, `val` и `idea` из [`css-course/kit.mjs`](css-course/kit.mjs). Превью собирает `page(css, html)`.
- Проверка задания `css(selector, property, label, { value | includes | within })` читает таблицу стилей ученика статически, через `apps/web/src/components/learning/css-rules.ts`. Перед сравнением значения нормализуются: нижний регистр, пробелы вокруг запятых, скобок и `/`. Вложенность `&` и @-правила учитываются, их задаёт `within`.
- Решение каждого задания проходит все проверки, а стартовый код хотя бы одну не проходит. Это проверяет тест.
- Markdown уроков рендерится без GFM, а разметку в вопросах пишут в обратных кавычках.
